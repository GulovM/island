# Kite Island

Динамический остров для Windows 10 и 11: тёмная «чёлка» по центру верхнего края экрана. Раскрывается при
наведении мыши и превращается в панель с семью основными вкладками (плюс собственные вкладки, центр уведомлений
и настройки). Рисуется на GPU (Direct2D поверх DirectComposition), в простое почти не нагружает процессор, exe
занимает около 2,5 МБ (≤ 3 МБ), а пиковое потребление памяти в Диспетчере задач составляет до ~55 МБ (зависит от
открытых вкладок и кэша иконок).

## Требования

- Windows 10 (версия 2004, сборка 19041) или Windows 11, x64
- Для сборки из исходников: Rust (stable, MSVC) и Windows SDK

## Установка

Скачайте со страницы Releases один из файлов:

- **`island-<версия>-setup.exe`** — установщик. Ставит в `%LOCALAPPDATA%\Programs\Island` без прав администратора,
  по желанию добавляет автозапуск и ярлык на рабочий стол. Удаляется через «Параметры → Приложения»; при удалении
  предлагает стереть настройки и кэш.
- **`island-<версия>-portable.zip`** — без установки: распакуйте куда угодно и запустите `island.exe`. В системе
  остаётся только значок в трее и папка настроек `%APPDATA%\island`.

Контрольные суммы лежат в `SHA256SUMS.txt`. Exe не подписан цифровой подписью, поэтому SmartScreen может показать
предупреждение: «Подробнее → Выполнить в любом случае».

История буфера обмена и «Быстрый доступ» хранятся в `%APPDATA%\island` в зашифрованном виде (DPAPI, привязка к вашей
учётной записи Windows); при переносе папки на другой компьютер или пользователя они не прочитаются.

Тихая установка: `island-<версия>-setup.exe /VERYSILENT /TASKS=autostart`.

Выйти из программы: правый клик по значку в трее → «Выход».

## Как пользоваться

- **Наведите мышь на верхний край экрана** — остров раскроется, уберите — свернётся.
- Свёрнутый остров показывает настраиваемые значки по краям (по умолчанию раскладку клавиатуры слева и Wi-Fi справа;
  можно выбрать раскладку, Wi-Fi / режим полёта, Bluetooth, батарею или убрать значок) и время по центру (при активном
  таймере — также плашку отсчёта). Когда играет музыка, по левому и правому краям свёрнутой чёлки анимируются живые
  стерео-аудиоволны (WASAPI); громкость, таймер и зарядка показываются короткими уведомлениями, а системные уведомления
  приложений и напоминания календаря — всплывающей капсулой под чёлкой.
- **Основные вкладки:** Controls (Wi-Fi, режим полёта, Bluetooth, звук и устройство вывода, ночной свет, тёмная тема, энергосбережение, батарея, плеер), Today (часы с 6 циферблатами, погода, календарь с собственными событиями, повторами, напоминаниями, синхронизацией и записью в Google Календарь и iCloud и ICS-ссылками, таймер, задачи с уровнями важности и сортировкой),
  Stats (процессор, видеокарта, память, диск, время работы, сеть и замер скорости), Clipboard («Быстрый доступ» и история буфера обмена), Apps (запуск приложений и быстрые ссылки),
  Wallpaper (смена обоев), Power (блокировка, сон, перезагрузка, выключение).
- **Уведомления:** иконка **колокольчика** рядом с шестерёнкой открывает центр системных уведомлений Windows
  (`UserNotificationListener`) и напоминаний календаря с бейджем непрочитанных, кнопками отметки «Прочитано»/очистки
  и правилами по приложениям (правый клик по карточке или список «Приложения»: обычные, беззвучные или отключены).
  Всплывающие капсулы автоматически ставятся на паузу, пока в Windows активен режим «Не беспокоить».
- **Кастомизация виджетов:** кнопка с карандашом справа в ряду вкладок (или долгое нажатие на пустом месте) открывает режим правки сетки на вкладках Controls, Today и Stats. Виджеты можно перетаскивать, скрывать в лоток («−») и менять их размер. По нажатию «Готово» остров автоматически подгоняется под видимое содержимое; при повторном входе в правку подсвеченные ручки по краям позволяют растянуть остров обратно.
- **Быстрый доступ** (вкладка Clipboard, раздел слева от «Буфера»): постоянное хранилище на 30 записей — файлы
  (хранится только путь; пропавший файл помечается «не найден»), ссылки, тексты и картинки. Перетащите файл, ссылку или
  текст на остров (в том числе на тонкую полоску): он покажет плашку «Быстрый доступ», бросьте на неё. Записи открываются
  по Enter (файлы и ссылки) или вставляются в прежнее окно (текст, картинки) и перетаскиваются из раздела наружу — в
  проводник, мессенджер, редактор. История «Буфера» хранится сутки и чистится сама; «Закрепить» (`Ctrl+P`) переносит запись
  в «Быстрый доступ».
- **Горячая клавиша** `Ctrl+Alt+Space` открывает вкладку Apps с поиском (меняется в `config.toml`). Свою горячую клавишу
  «Быстрого доступа» назначают прямо в разделе: кнопка «Назначить горячую клавишу» вверху справа, затем сочетание.
- Правый клик по раскрытому острову включает режим «полоски»: поверх окон, развёрнутых на весь экран,
  остров сворачивается в тонкую линию.
- В полноэкранных играх (DirectX) остров скрывается сам.

## Эффект стекла (iOS 26 Liquid Glass)

Раскрытый остров оформлен в стиле жидкого стекла iOS 26 с размытием фона, световой кромкой и бликами. В «Настройках» (раздел «Внешний вид»):
- **Стекло** (ключ `glass`, по умолчанию `1`) — включает полупрозрачное стекло; при `0` тело острова сплошное.
- **Прозрачность** (ключ `glass_opacity`, 0–100, по умолчанию `70`, в стиле `Windows`) — степень прозрачности тела раскрытого острова.
- **Материал** (ключ `material`, по умолчанию `regular`, в стиле `macOS`) — пять вариантов плотности: `Ultrathin`, `Thin`, `Regular`, `Thick`, `Chrome`.
- **Стиль цветов** (ключ `palette_style`, по умолчанию `windows`) — палитра Windows (цвета системы) либо системные цвета iOS 26 (в Настройках «macOS»; прежнее значение `ios` тоже работает).

Если в Windows выключены «Эффекты прозрачности», размытия нет, а тело становится плотнее. Остров остаётся полностью виден в записи экрана, трансляциях (OBS) и на скриншотах.

## Настройки

Нажмите на **шестерёнку** справа в ряду вкладок. Сверху — разделы **«Внешний вид»**, **«Вкладки»** и **«Система»**:
в каждом только его настройки, выбранный раздел запоминается до выхода из программы.

- **Стекло**, **Прозрачность**, **Материал**, **Стиль цветов**, **Акцентная капля** и **Масштаб интерфейса** — параметры стекла iOS 26, стиль палитры (`Windows` или `macOS`; «Прозрачность» доступна в стиле Windows, а «Материал» — в macOS), цвет капли активной вкладки и общий масштаб UI.
- **Цвет системы** — палитра острова берётся из Windows: акцент и фон подстраиваются под цвета системы.
  Если Wallpaper Engine (или сама Windows) подбирает цвет акцента по обоям, остров меняется вместе с ним.
- **Цвета** — полная палитра: выберите, что красить (акцент или фон), и двигайте квадрат насыщенности и яркости
  и полосу оттенка либо введите `#RRGGBB`. Рядом шесть готовых тем. Текст и карточки подстраиваются под яркость
  фона, поэтому светлый фон тоже читается.
- **Радиус углов** — ползунок. Пока вы его тянете, остров подсвечивается, чтобы скругление было хорошо видно.
- **Вкладки** — переключатели включают и выключают вкладки (до 8 одновременно), порядок меняется **перетаскиванием мышью**; здесь же создаются, переименовываются и удаляются собственные вкладки.
- **Система** — **автозапуск**, **время и настраиваемые значки** на свёрнутом острове (левый/правый слот), **режим свёрнутого острова** («Авто» или «Всегда полоска»), **полоска** над развёрнутыми окнами, автоудаление выполненных задач в новый день, свободная раскладка виджетов, скрытие при скриншотах, **язык**, **всплывающие уведомления** и **обновления** (ручная проверка и автообновление).
- «Сбросить внешний вид» возвращает всё по умолчанию.

Изменения применяются сразу и сохраняются в `%APPDATA%\island\config.toml`.

## config.toml

Файл создаётся при первом запуске с комментариями. Кроме настроек внешнего вида в нём:

| Ключ | Что делает |
|---|---|
| `glass` | эффект стекла: 1 — вкл, 0 — сплошное тело |
| `glass_opacity` | прозрачность тела раскрытого острова в стиле Windows, 0–100 (по умолчанию 70) |
| `material` | материал стекла в стиле macOS: `ultrathin`, `thin`, `regular` (по умолчанию), `thick`, `chrome` |
| `palette_style` | стиль палитры: `windows` (по умолчанию) или `macos` (раньше `ios`, оно тоже принимается) |
| `accent_pill` | 1 — капля вкладки цветом акцента, 0 — нейтральная |
| `system_colors`, `accent`, `bg`, `corner_radius` | цвета Windows или пользовательские `#RRGGBB` и радиус нижних углов |
| `tabs`, `hidden_tabs`, `custom_tabs` | порядок вкладок, скрытые вкладки и собственные вкладки (номер, название и раскладка через `\|`) |
| `idle_face`, `collapsed_left`, `collapsed_right` | время и значки слева/справа на свёрнутом острове (`layout`, `wifi`, `bluetooth`, `battery`, `none`) |
| `collapsed_mode` | `auto` (чёлка, а над окнами на весь экран — полоска) или `strip` (всегда полоска) |
| `strip_over_maximized` | 1 — над окнами на весь экран остров становится тонкой полоской (не закрывает вкладки браузера) |
| `live_media`, `live_toasts`, `popup_notifications` | аудиоволны музыки на краях чёлки, короткие тосты (таймер, громкость, зарядка) и всплывающие капсулы уведомлений (1 — вкл, 0 — выкл) |
| `todo_clean_done`, `free_layout`, `hide_on_screenshot` | автоочистка выполненных задач в новый день, свободная раскладка сетки, скрытие при скриншотах (1/0) |
| `leave_delay_ms`, `env_poll_ms` | задержка сворачивания (мс) и период проверки полноэкранных окон (мс) |
| `collapsed_width`, `collapsed_height` | размер свёрнутого острова (логические пиксели) |
| `hotkey` | глобальная горячая клавиша для вкладки Apps (`""` — отключить) |
| `quick_hotkey` | глобальная горячая клавиша раздела «Быстрый доступ» (по умолчанию не назначена; обычно её назначают в самом разделе) |
| `wallpaper_dir` | папка с обоями для вкладки Wallpaper |
| `weather_city`, `clock_style` | город для погоды на вкладке Today (пусто — по IP через ipwho.is) и циферблат часов (`0`–`5`) |
| `calendar_ics`, `layout_controls`, `layout_today`, `layout_stats` | ICS-ссылки календаря и сохранённые раскладки виджетов (`v2`); Google и iCloud подключаются во вкладке Today |
| `ui_scale` | множитель к масштабу Windows, 0.9–2.0 (по умолчанию 1.2); в Настройках показан итоговый процент |
| `language`, `auto_update` | язык интерфейса (`auto`, `ru`, `en`) и автоматическая установка обновлений (`0`/`1`) |
| `[snippets]` | быстрые ссылки во вкладке Apps: `имя = "адрес"` |

Файл можно править вручную: меню трея → «Открыть config.toml», затем «Перечитать конфиг».

## Сборка из исходников

```powershell
cargo build --release          # island\target\release\island.exe
cargo test                     # модульные тесты
powershell -ExecutionPolicy Bypass -File tools\package.ps1   # portable-архив, установщик и SHA256SUMS.txt в dist\
```

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`); без него
`package.ps1` соберёт только zip. Скрипт установщика — `installer\island.iss`. Как выпустить релиз —
в [CONTRIBUTING.md](CONTRIBUTING.md).

Если в системе есть Windows SDK (`rc.exe`), в exe вшиваются иконка и сведения о версии; без него сборка
проходит, но exe будет без иконки.

## Если что-то не работает

- Лог: `%APPDATA%\island\island.log`.
- «Не удалось занять горячую клавишу» — сочетание занято другой программой; поменяйте `hotkey` в `config.toml`.
- Остров не реагирует на верх экрана при включённом режиме «полоски» (точка слева в ряду вкладок) — выключите его
  правым кликом по раскрытому острову.

## Происхождение проекта

Kite Island — независимая реализация, вдохновлённая приложением **Hitodama** (Mainak Deb Das, Otism). Код написан с нуля;
поведение оригинала изучалось по его наблюдаемой работе (reverse engineering), исходный код и ресурсы оригинала
**не копировались**. Проект не связан с авторами Hitodama и **не является коммерческим**: бесплатный, без рекламы
и сбора данных. Подробнее — в [NOTICE.md](NOTICE.md).
