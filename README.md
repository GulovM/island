# Island

Динамический остров для Windows 10 и 11: тёмная «чёлка» по центру верхнего края экрана. Раскрывается при
наведении мыши и превращается в панель с семью вкладками. Рисуется на GPU (Direct2D поверх
DirectComposition), в простое не потребляет процессор и занимает несколько мегабайт памяти.

## Требования

- Windows 10 (версия 2004, сборка 19041) или Windows 11, x64
- Для сборки из исходников: Rust (stable, MSVC) и Windows SDK

## Установка

Скачайте со страницы Releases один из файлов:

- **`island-<версия>-setup.exe`** — установщик. Ставит в `%LOCALAPPDATA%\Programs\Island` без прав администратора,
  по желанию добавляет автозапуск и ярлык на рабочий стол. Удаляется через «Параметры → Приложения»; при удалении
  предлагает стереть настройки и кэш.
- **`island-<версия>-portable.zip`** — без установки: распакуйте куда угодно и запустите `island.exe`. В системе
  остаётся только значок в трее и папка настроек `%APPDATA%\island`.

Контрольные суммы лежат в `SHA256SUMS.txt`. Exe не подписан цифровой подписью, поэтому SmartScreen может показать
предупреждение: «Подробнее → Выполнить в любом случае».

История буфера обмена хранится в `%APPDATA%\island` в зашифрованном виде (DPAPI, привязка к вашей учётной записи Windows);
при переносе папки на другой компьютер или пользователя история не прочитается.

Тихая установка: `island-<версия>-setup.exe /VERYSILENT /TASKS=autostart`.

Выйти из программы: правый клик по значку в трее → «Выход».

## Как пользоваться

- **Наведите мышь на верхний край экрана** — остров раскроется, уберите — свернётся.
- Свёрнутый остров без музыки показывает раскладку клавиатуры (слева), время (по центру) и Wi-Fi (справа).
  Когда играет музыка, вместо этого — мини-плеер; громкость, таймер и зарядка показываются короткими уведомлениями.
- **Вкладки:** Controls (Wi-Fi, Bluetooth, звук, ночной свет, тёмная тема, плеер), Today (часы, погода, календарь, таймер, задачи),
  Stats (процессор, видеокарта, память, сеть), Clipboard (история буфера обмена), Apps (запуск приложений),
  Wallpaper (смена обоев), Power (блокировка, сон, перезагрузка, выключение).
- **Горячая клавиша** `Ctrl+Alt+Space` открывает вкладку Apps с поиском (меняется в `config.toml`).
- Правый клик по раскрытому острову включает режим «полоски»: поверх окон, развёрнутых на весь экран,
  остров сворачивается в тонкую линию.
- В полноэкранных играх (DirectX) остров скрывается сам.

## Настройки

Нажмите на **шестерёнку** справа в ряду вкладок:

- **Цвет системы** — палитра острова берётся из Windows: акцент и фон подстраиваются под цвета системы.
  Если Wallpaper Engine (или сама Windows) подбирает цвет акцента по обоям, остров меняется вместе с ним.
- **Цвета** — полная палитра: выберите, что красить (акцент или фон), и двигайте квадрат насыщенности и яркости
  и полосу оттенка либо введите `#RRGGBB`. Рядом шесть готовых тем. Текст и карточки подстраиваются под яркость
  фона, поэтому светлый фон тоже читается.
- **Радиус углов** — ползунок. Пока вы его тянете, остров подсвечивается, чтобы скругление было хорошо видно.
- **Вкладки** — переключатели включают и выключают вкладки, стрелки меняют порядок.
- **Автозапуск** и **время, раскладка и Wi-Fi** на свёрнутом острове — переключатели.
- «Сбросить внешний вид» возвращает всё по умолчанию.

Изменения применяются сразу и сохраняются в `%APPDATA%\island\config.toml`.

## config.toml

Файл создаётся при первом запуске с комментариями. Кроме настроек внешнего вида в нём:

| Ключ | Что делает |
|---|---|
| `leave_delay_ms` | задержка сворачивания после ухода мыши |
| `collapsed_width`, `collapsed_height` | размер свёрнутого острова |
| `hotkey` | глобальная горячая клавиша для вкладки Apps (`""` — отключить) |
| `wallpaper_dir` | папка с обоями для вкладки Wallpaper |
| `weather_city` | город для погоды на вкладке Today (пусто — по IP через ipwho.is; меняется и кликом по карточке погоды) |
| `calendar_ics` | ссылка на календарь в формате iCal («секретный адрес» Google Calendar); вводится и в острове: клик по карточке календаря |
| `ui_scale` | множитель к масштабу Windows, 0.9–2.0 (по умолчанию 1.2); в Настройках показан итоговый процент (например, 125 % × 1.2 = 150 %) |
| `language` | язык интерфейса: `auto` (как в Windows), `ru`, `en`; меняется и в Настройках |
| `strip_over_maximized` | 1 — над окнами на весь экран остров становится тонкой полоской (не закрывает вкладки браузера) |
| `live_media`, `live_toasts` | мини-плеер и уведомления в свёрнутом виде (1 — вкл, 0 — выкл) |
| `[snippets]` | быстрые ссылки во вкладке Apps: `имя = "адрес"` |

Файл можно править вручную: меню трея → «Открыть config.toml», затем «Перечитать конфиг».

## Сборка из исходников

```powershell
cargo build --release          # island\target\release\island.exe
cargo test                     # модульные тесты
powershell -ExecutionPolicy Bypass -File tools\package.ps1   # portable-архив, установщик и SHA256SUMS.txt в dist\
```

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`); без него
`package.ps1` соберёт только zip. Скрипт установщика — `installer\island.iss`. Как выпустить релиз —
в [CONTRIBUTING.md](CONTRIBUTING.md).

Если в системе есть Windows SDK (`rc.exe`), в exe вшиваются иконка и сведения о версии; без него сборка
проходит, но exe будет без иконки.

## Если что-то не работает

- Лог: `%APPDATA%\island\island.log`.
- «Не удалось занять горячую клавишу» — сочетание занято другой программой; поменяйте `hotkey` в `config.toml`.
- Остров не реагирует на верх экрана при включённом режиме «полоски» (точка слева в ряду вкладок) — выключите его
  правым кликом по раскрытому острову.
