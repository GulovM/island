## [0.2.2] — 2026-10-17

### Добавлено

- Полоска яркости экрана на вкладке «Управление» (панель ноутбука или внешний монитор по DDC/CI); скрыта, если устройство яркость не поддерживает.
- Настройки: «Масштаб интерфейса» (90–200 %, ключ `ui_scale`) — шрифты и панель растут вместе; применяется при отпускании ползунка, окно не выходит за границы монитора.
- Today: ссылка на календарь вводится прямо в острове (клик по «Календарь не подключён» или по карточке события; `https://`, `http://`, `webcal://`, пусто — отключить).
- Два языка интерфейса — русский и English (ключ `language`: `auto`/`ru`/`en`, переключатель в Настройках, по умолчанию — язык Windows); названия вкладок тоже переведены.
- Настройки: переключатель «Над окнами на весь экран — полоска» (ключ `strip_over_maximized`, по умолчанию вкл): остров не закрывает вкладки браузера; раскрывается при наведении на верхний край. Прежний выбор из `strip.txt` переносится автоматически.
- Анимации: плавное появление и сдвиг задач, отметка «выполнено», переход между неделей и месячным календарём.
- Apps: клавиша Delete скрывает выбранное приложение из списка (`apps_hidden.txt`).

### Изменено
- Интерфейс просторнее: больше отступы и панели; Today шире (больше места задачам), в Stats крупнее «Топ приложений» (иконки и текст), карусель Wallpaper крупнее.
- Масштаб в Настройках показывает итоговый процент с учётом масштаба Windows; по умолчанию — 150 % при 125 % в системе (шаг 5 %).

### Исправлено
- Буфер обмена: изображения (скриншоты и скопированные) снова сохраняются и показываются — шифрование PNG падало из-за открытого файла; повторное уведомление о том же снимке не создаёт дубль.
- Буфер обмена: при открытии выбирается первая запись, поэтому кнопки «Вставить / Копировать / Закрепить / Удалить» работают сразу.
- Настройки: убрано пустое место в обеих карточках.
- Wallpaper: превью чётче (384×216 вместо 160×90), боковые карточки обрезаются по краям, а не сжимаются по ширине.
- Today: длинные задачи переносятся (до 3 строк) вместо обрезки «…»; текст в поле ввода не заходит под кнопки.
- Apps: ярлыки `.lnk`/`.url` на удалённые программы и игры больше не показываются; неудачный запуск не попадает в «Недавние» и не увеличивает счётчик.

## [0.2.1] — 2026-10-17

### Добавлено
- Поддержка Windows 10 (2004+, сборка 19041): манифест (Per-Monitor V2, длинные пути, UTF-8), запасные шрифты (Segoe UI, Segoe MDL2 Assets), запасной рендер WARP без GPU, статичная CRT (не нужен VC++ Redistributable).
- Календарь: `COUNT` для еженедельных/ежемесячных/ежегодных повторов, переход на летнее время по дате события.
- История буфера обмена (текст и картинки) шифруется DPAPI: файлы читаются только вашей учётной записью Windows. Старые открытые файлы переводятся автоматически.
- `tools/package.ps1` и CI подписывают exe и установщик (Authenticode), если задан сертификат (`ISLAND_SIGN_PFX`/`ISLAND_SIGN_THUMBPRINT`, секреты `SIGN_PFX_BASE64`/`SIGN_PFX_PASSWORD`); без сертификата сборка не подписывается.

### Исправлено
- Ложные Ctrl+C/V/A при AltGr; потеря файлов истории при невалидном UTF-8; запись файлов теперь атомарна.
- Зависание командного потока из-за WinRT-вызовов (Wi-Fi, Bluetooth, медиа): ожидание ограничено 5 с.
- Отключение Wi-Fi больше не блокирует интерфейс; пути «Изображения», Windows и системный диск берутся из системы.
- Сборка: `--locked`, clippy в CI, проверка версии тега; установщик закрывает остров сначала мягко.

### Изменено
- `main.rs` разделён на модули (`wnd`, `window`, `events`, `input`, `render`), `Gfx` вынесен в `src/gfx.rs`; ширина подписей считается по раскладке DirectWrite, а не по числу символов.

## [0.2.0] — 2026-10-16

### Добавлено
- Today: месячный календарь. Раскрывается кнопкой рядом с «Эта неделя» или кликом по дню недели,
  дни с событиями помечены точками, клик по дню показывает его события.
- Today: редактирование задач (карандаш на строке, текст правится в поле внизу).
- Календарь: многодневные события, `EXDATE`, перенесённые вхождения повторов, отменённые события;
  «Ближайшее событие» обновляется раз в минуту, при ошибке загрузки показывается сообщение.

### Исправлено
- `calendar_ics` и `weather_city`, оказавшиеся под `[keys]`, молча игнорировались; теперь применяются, в лог пишется подсказка.
- Today: кнопки на строках задач и поверх поля ввода (удаление, «+») не срабатывали, потому что нажатие забирала нижняя область.

## [0.1.1] — 2026-10-16

### Изменено
- Stats: в «Топ приложений» вместо первых букв названий показываются иконки программ.

## [0.1.0] — 2026-10-16

Первый публичный выпуск.

### Добавлено
- Остров по центру верхнего края экрана: раскрывается при наведении, семь вкладок
  (Controls, Today, Stats, Clipboard, Apps, Wallpaper, Power).
- Свёрнутый вид: раскладка, время, Wi-Fi, мини-плеер, уведомления о громкости, таймере и зарядке.
- Настройки: цвета системы и своя палитра, радиус углов, порядок и состав вкладок, автозапуск.
- Глобальная горячая клавиша для вкладки Apps, `config.toml`.
- Установщик (Inno Setup, установка без прав администратора) и portable-архив, `SHA256SUMS.txt`.
- Лицензия MIT.
