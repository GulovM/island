# Action Sheets (Панели действий)

> Источник: Figma Component Set `507:24669`, подтвержденный инстансами в Canvas `Examples` (`0:3329`) и `Materials` (`215:105157`), файл `omHrdST5YSkR9on4fczusp` (iOS and iPadOS 26 Community).  
> Все числовые характеристики извлечены без округлений.

---

## Описание
Нижние всплывающие меню для выбора сценариев

---

## 1. Размеры (Dimensions)
- **width**: `fill (с отступами 10 pt по краям на iPhone) или 375 pt`
- **action_button_height**: `56 pt`
- **cancel_button_height**: `56 pt`

## 2. Отступы (Paddings & Spacing)
- **container_padding**: `14px`
- **sheet_gap**: `8px (между группой действий и кнопкой 'Cancel')`

## 3. Радиусы скругления (Border Radius)
- **action_group**: `26px / 14px`
- **cancel_button**: `26px / 14px`

## 4. Заливки и обводки (Fills & Strokes)
- **group_bg_light**: `rgba(255, 255, 255, 0.85) + blur(50px)`
- **group_bg_dark**: `rgba(30, 30, 30, 0.85) + blur(50px)`
- **cancel_bg_light**: `#FFFFFF`
- **cancel_bg_dark**: `#1C1C1E`

## 5. Слои эффектов (Effects: Shadows & Blur)
- **box_shadow**: `0px 10px 40px 0px rgba(0, 0, 0, 0.18)`

## 6. Состояния и варианты (States: Normal, Pressed, Selected, Disabled)
- **normal**: Штатное состояние
- **pressed**: Подсветка строки rgba(0, 0, 0, 0.06)
- **destructive**: Красный текст #FF383C
