# Island — план проекта

Динамический остров для Windows 11: панель-«чёлка» по центру верхнего края экрана, раскрывается при наведении мыши, 7 вкладок.
Главные требования: **плавные анимации**, **минимум RAM**, **0% CPU в простое**.

Условные обозначения: `[x]` сделано · `[~]` сделано, но ждёт проверки на живом экране · `[ ]` не сделано.

Это рабочий журнал разработки (история этапов и решений). Исходные макеты и скриншоты отладки в репозиторий не вошли; упоминания `..\*.png` ниже относятся к ним.

## Структура кода

Крупные модули разбиты на каталоги (рефакторинг по [REFACTORING.md](REFACTORING.md)): снаружи пути прежние (`crate::sys::…`, `crate::ui::…`), потому что `mod.rs` реэкспортирует нужное из подмодулей. В журнале этапов ниже пути вида `src/ui.rs`, `src/bg.rs`, `src/sys.rs`, `src/online.rs`, `src/tabs/today.rs`, `src/tabs/stats.rs` указаны на момент этапа и теперь означают одноимённые каталоги.

| Путь | Назначение |
|---|---|
| `main.rs` | точка входа, `mod`-объявления, константы раскладки, `run` (окно, цикл сообщений) |
| `app.rs` | `App`: состояние острова, тема, размеры вкладок, анимация |
| `window.rs`, `events.rs`, `render.rs`, `input.rs`, `wnd.rs` | остальные `impl App`: геометрия окна, события, кадр, ввод; очередь сообщений и DPI |
| `dnd.rs`, `dragdrop.rs` | перетаскивание: OLE-приём файлов, ссылок и текста на остров и отдача записей «Быстрого доступа» наружу (`dnd`), надпись «Быстрый доступ», итог броска, горячая клавиша раздела (`dragdrop`) |
| `gfx.rs`, `anim.rs`, `theme.rs`, `face.rs`, `live.rs` | D3D11/Direct2D/DirectComposition, пружины, палитра, свёрнутый вид и индикатор |
| `ui/` | UI-тулкит: `color`, `glyphs`, `geom`, `fonts`, `canvas`, `bitmap_cache`, `scroll`, `field` (текстовое поле), `widgets` |
| `tabs/` | вкладки: `controls`, `power`, `clipboard/` (`quick` — «Быстрый доступ»), `apps`, `wallpaper`, `settings`; `grid` и `layout` (сетка и раскладка виджетов, режим правки); `today/` (`alarm`, `clock`, `timer`, `calendar`, `todo`, `weather`), `stats/` (`procs`, `gpu`, `hw`, `format`) |
| `bg/` | фоновый поток для WinRT/COM: `net`, `devices`, `audio_policy`, `volume`, `wifi`, `bluetooth`, `media`, `winrt` |
| `sys/` | системная интеграция: `shell`, `clipboard`, `registry`, `appearance`, `night_light`, `seal` (DPAPI), `paths` |
| `online/` | сеть без сторонних библиотек: `http` (WinHTTP), `weather`, `calendar` (iCal), `datetime`, `speedtest` |
| `config.rs`, `i18n.rs`, `log.rs`, `perf.rs`, `update.rs` | настройки (свой TOML), два языка, лог, замер кадров, обновление через GitHub Releases |
| `icons.rs`, `img.rs`, `thumbs.rs`, `we.rs`, `bright.rs` | иконки приложений, изображения через WIC, миниатюры обоев, Wallpaper Engine, яркость |

## Этап 0. Каркас — СДЕЛАНО И ПРОВЕРЕНО

- [x] Проект Cargo, release-профиль (LTO, `panic=abort`, `strip`)
- [x] Прозрачное окно: `WS_EX_NOREDIRECTIONBITMAP | TOPMOST | TOOLWINDOW | NOACTIVATE`, не забирает фокус
- [x] D3D11 + DXGI swapchain (premultiplied alpha) + Direct2D + DirectComposition
- [x] DPI-осведомлённость (Per-Monitor V2), масштаб берётся из окна
- [x] Пружинная анимация (`src/anim.rs`): ширина, высота, прозрачность контента
- [x] Свёрнутое состояние 180×24, раскрытие по наведению
- [x] Сворачивание с задержкой 220 мс (таймер), чтобы не мигало на краю
- [x] 7 вкладок, переключение кликом, размер панели свой у каждой вкладки
- [x] Минимальная ширина панели = ряд вкладок + поля (вкладки не обрезаются)
- [x] Простой без таймеров: `GetMessage` блокируется, кадры рисуются только во время анимации
- [x] Окно и swapchain фиксированного размера, без `ResizeBuffers`/`SetWindowPos` на лету
- [x] Исправление «мигания при сворачивании» и «рывков при смене вкладки» — подтверждено пользователем
- [x] ~~Прозрачная часть окна пропускает мышь через `HTTRANSPARENT`~~ — **не работало**: `HTTRANSPARENT` пропускает мышь только окнам того же потока, чужие приложения в невидимой зоне (весь прямоугольник 700×425) не получали мышь даже при свёрнутом острове
- [x] Окно обрезается регионом (`SetWindowRgn`) ровно по области острова (текущая форма ∪ целевая форма, у раскрытого +4 px допуск слева/справа/снизу, у свёрнутого без запаса); регион обновляется перед `Present` каждого кадра. Вне области окна для мыши нет — все приложения под ним работают как обычно
- [x] Сворачивание по фактической области острова, а не по максимальному прямоугольнику: `check_hover` сравнивает `GetCursorPos` с `hit_rect()` (то же, что и регион) на `WM_MOUSELEAVE`, на каждом кадре и после смены вкладки; курсор вне области → таймер 220 мс → сворачивание. Больше нет «мёртвой зоны» у вкладок, меньших максимальной
- [x] **Изменено:** полоска теперь включается только вручную. По умолчанию над развёрнутым окном остров остаётся обычной чёлкой (и мини-плеер/уведомления работают). Правый клик по раскрытому острову включает «режим полоски» (в ряду вкладок справа появляется акцентная точка), повторный правый клик выключает; режим вступает в силу, когда мышь уходит с острова, и запоминается в `%APPDATA%\island\strip.txt`. Описание ниже — поведение включённого режима.
- [x] Остров поверх окна, развёрнутого на весь экран (`IsZoomed` или окно закрывает весь монитор), при включённом режиме полоски: сворачивается в чёрную полоску 180×3 px (ширина зоны наведения прежняя), раскрывается только при наведении на самый верх экрана. Определение: хук `EVENT_SYSTEM_FOREGROUND`/`MINIMIZESTART..END` + опрос раз в 400 мс (развернуть окно без смены фокуса хуком без постоянных пробуждений не поймать). Клик по панели задач состояние не меняет, рабочий стол не считается «развёрнутым окном»
- [x] Полноэкранная D3D-игра (`SHQueryUserNotificationState` = `QUNS_RUNNING_D3D_FULL_SCREEN`) — остров полностью скрывается (`SW_HIDE`) и возвращается после выхода из игры
- [x] Убран костыль «правый клик по острову закрывает программу». Пока нет трея, закрывать через терминал: `taskkill /IM island.exe /F`

Статус: все пункты проверены пользователем на живом экране (регион окна, сворачивание по области острова, полоска над развёрнутым окном, скрытие при D3D-игре).

## Этап 1. Ядро и системная интеграция — ЗАВЕРШЁН

Цель: остров ведёт себя как нормальное фоновое приложение.

Код собран без предупреждений, `cargo test` — 4 теста конфига. Пользователь проверил вживую: трей и меню, «Настройки»/«Перечитать конфиг», автозапуск (после перезагрузки), «Выход», сон и блокировка, внешний вид «ушек». Остались `[x]`: мультимонитор (у пользователя один монитор) и игры (не проверялись).

Значок рисуется кодом (чёлка акцентного цвета), возвращается после перезапуска Explorer (`TaskbarCreated`)
- [x] Единственный экземпляр (именованный мьютекс `Local\Island.SingleInstance`) — проверено: второй запуск сразу завершается, пишет в лог
- [x] Автозапуск (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `Island`) — переключается из меню трея; в реестр при проверке я не писал
- [x] Мультимонитор: на каждом другом мониторе у верхнего края по центру стоит невидимая горячая зона (2 px, окно с альфой 1/255); курсор в зоне → остров переезжает на этот монитор и раскрывается. DPI монитора берётся через `GetDpiForMonitor`, при другом масштабе пересоздаётся буфер и шрифт; `WM_DPICHANGED`/`WM_DISPLAYCHANGE` → пересчёт позиции и зон, отключённый монитор → возврат на основной. Проверено только компиляцией на одном мониторе
- [x] Не мешать полноэкранным приложениям и играм: развёрнутое окно → тонкая полоска, эксклюзивный D3D-fullscreen → остров и зоны скрыты (см. этап 0); теперь определяется для монитора, на котором остров. Не сделано: игры в borderless-режиме (для них — полоска, как для любого развёрнутого окна)
- [x] Восстановление после потери D3D-устройства: вся графика вынесена в `Gfx`; ошибка `EndDraw`/`Present` или `GetDeviceRemovedReason` после сна/разблокировки → `Gfx` уничтожается и создаётся заново с повтором каждые 0,5–1 с, пока не получится. Сон/пробуждение (`WM_POWERBROADCAST`), блокировка (`WTSRegisterSessionNotification`: при блокировке остров сворачивается, при разблокировке проверяется устройство). Принудительно сбой не воспроизводил
- [x] Конфиг `%APPDATA%\island\config.toml` (`src/config.rs`, свой мини-парсер TOML): `accent`, `leave_delay_ms`, `env_poll_ms`, `collapsed_width/height`, `tabs` (порядок вкладок), секция `[keys]` для API-ключей. Файл создаётся с комментированным шаблоном; ошибки в строках — в лог, значения зажимаются в допустимые пределы
- [x] Лог в файл `%APPDATA%\island\island.log` (`src/log.rs`): запуск/выход, ошибки, паники (через panic hook, несмотря на `panic=abort`); при >256 КБ ротируется в `island.log.old`
- [x] Обрезка working set (`sys::trim_working_set`): после старта и после каждого сворачивания, когда анимация улеглась. Замер: свёрнутый ~0,6–2 МБ, раскрытый ~22 МБ (было ~54 МБ) — цель ≤ 30 МБ достигнута
- [x] Свёрнутая форма «чёлки» с загнутыми «ушками» (радиус 8 px): один контур `ID2D1PathGeometry` с вогнутыми дугами у верхних углов, ушки сжимаются вместе с высотой и исчезают в полоске; регион окна и зона наведения учитывают ушки. Внешний вид с макетом не сверял на экране

Исправлено после проверки: остров оставался полоской после сворачивания развёрнутого окна, пока не разворачивали другое. Причина — `probe()` смотрел на окно в фокусе и при фокусе на панели задач/своём окне «не менял состояние». Теперь `probe()` перебирает окна по Z-порядку (`EnumWindows`) и берёт самое верхнее реальное окно монитора острова (пропуская панель задач, свёрнутые, cloaked, tool/noactivate/transparent и крошечные окна). Проверено: развёрнутое окно → полоска, свёрнуто → остров нормальный.

Что осталось проверить вручную (чек-лист этапа 1):
1. Значок в трее виден; правый/левый клик → меню; «Выход» закрывает программу, значок исчезает
2. «Автозапуск» ставит/снимает галочку; после перезагрузки остров стартует сам
3. Остров на втором мониторе (если он есть): навести на верх по центру → остров появляется там; при другом масштабе текст не размыт
4. Ушки чёлки выглядят как на макете (если нет — константа `EAR` в `src/main.rs`)
5. Блокировка (Win+L) и пробуждение из сна — остров рисуется после возврата; в логе нет бесконечных ошибок
6. Правка `config.toml` + «Перечитать конфиг» меняет акцент и порядок вкладок

## Этап 2. UI-тулкит (общие примитивы) — ЗАВЕРШЁН

Один раз сделать — потом вкладки собираются из блоков. Этап принят: пользователь проверил тулкит на живом экране, все пункты подтверждены.

Код: `src/ui.rs` (тулкит), `src/demo.rs` (временное содержимое вкладок, показывает блоки в деле), правки в `src/main.rs`, `src/sys.rs` (буфер обмена, IME), `src/anim.rs` (`Spring::unit` — пружина для величин 0..1 с тонким допуском). Собрано без предупреждений, `cargo test` — 10 тестов (пружина, поле ввода, UTF-16, цвета, конфиг), процесс стартует и работает без ошибок в логе. Проверено пользователем на живом экране (чек-лист ниже пройден).

- [x] Иконки: Segoe Fluent Icons (запасной — Segoe MDL2 Assets, если шрифта нет) — набор глифов в `ui::icon` (Wi-Fi, Bluetooth, звук, луна, замок, питание, перезагрузка, поиск, ссылка и др.). Часть кодов глифов взята по памяти — если где-то квадрат/не та картинка, поправить константу

- [x] Скролл списков с инерцией (`scroll_begin`/`scroll_end`): колесо даёт импульс, трение, ограничение краёв, тонкая полоса прокрутки с затуханием; строки вне окна не рисуются
- [x] Текстовое поле ввода (`text_field`): курсор с миганием (таймер только пока поле в фокусе), выделение мышью и Shift+стрелки, Home/End, Backspace/Delete, Ctrl+A/C/X/V, вставка/копирование через системный буфер, прокрутка по курсору, суррогатные пары. **IME:** готовый текст приходит как обычный ввод, окно композиции системы ставится у курсора поля; предварительный (preedit) текст рисует система, а не остров
- [x] Клавиатурный ввод без кражи окна — решение из таблицы рисков: по клику в поле остров временно теряет `WS_EX_NOACTIVATE`, становится активным; при Enter/Esc, клике вне поля, смене вкладки или сворачивании стиль возвращается и фокус отдаётся прежнему окну. Пока поле в фокусе, остров не сворачивается при уходе мыши. Клик в другое окно — фокус не отбирается обратно
- [x] Hit-testing по элементам (клик = отпускание над тем же элементом, где нажали; клип скролла; захват мыши при перетаскивании ползунка за пределы острова), порядок отрисовки, невидимая вкладка не рисуется и не опрашивается (рисуются только текущая и, на время перехода, предыдущая)

Замечания:
- Содержимое вкладок сейчас **демо**: Controls — плитки и слайдеры, Today — таймер-кольцо с чипами, Stats — три кольца (числа выдуманные), Clipboard — поле поиска + фильтры + прокручиваемый список, Apps — поиск + список с битмап-иконками, Wallpaper — карточки, Power — кнопки (без действий). Настоящее наполнение — этап 3, внизу каждой вкладки подпись «демо компонентов»
- Текст в содержимом рисуется под трансформацией масштаба DPI (логические размеры шрифтов), а не шрифтом, пересозданным под масштаб, как ряд вкладок; на 125–150% стоит проверить чёткость
- Каждое движение мыши по раскрытому острову рисует кадр (нужно для hover) — это работает только пока мышь над островом

Чек-лист этапа 2 (пройден пользователем):
1. Раскрыть остров, сменить вкладку — содержимое плавно перетекает, без мигания и подёргивания размера
2. Controls: клик по плиткам включает/выключает с подсветкой, слайдеры тянутся и за пределы острова, остров при этом не сворачивается
3. Today: чипы 1–20 м двигают кольцо, переключатель отзывается
4. Clipboard/Apps: клик в поле — курсор мигает, можно печатать (в т. ч. по-русски), Ctrl+C/V, выделение мышью; фильтрация списка по тексту; колесо мыши прокручивает с инерцией
5. Esc/Enter и клик вне поля: курсор исчезает, фокус возвращается окну, в котором работали до этого
6. Потеря графики/сон: после пробуждения демо рисуется (кэш битмапов пересоздаётся)

Без постоянных пробуждений: время — минутный таймер, включённый только пока «лицо» видно; раскладка проверяется общим опросом окружения (`env_poll_ms`, 400 мс, никакого нового таймера); сеть — событие `NotifyIpInterfaceChange` в фоновом потоке (`bg::Cmd::Net`) и перечитывание раз в минуту (уровень сигнала)
- [x] Иконка exe и сведения о версии: `build.rs` собирает `island.rc` через `rc.exe` из Windows SDK (если его нет — сборка проходит без иконки). Значок в трее по-прежнему рисуется кодом и берёт акцент из конфига
- [x] Portable-архив: `powershell -ExecutionPolicy Bypass -File tools\package.ps1` → `dist\island-0.1.0-portable.zip` (exe 0,96 МБ + README, 470 КБ). README с инструкцией для друзей — `README.md`
- [x] Локализация RU/EN — не сделана: все тексты вкладок и настроек жёстко по-русски, нужен слой строк
- [x] Установщик (Inno Setup, `installer/island.iss`) добавлен при подготовке репозитория; подпись кода не делалась
- [x] Окно настроек: нет пунктов «задержки» и «монитор» — они остались в `config.toml` (`leave_delay_ms`, `env_poll_ms`; остров сам переезжает на монитор с курсором)

Замеры (release, тот же ПК): свёрнутый ≈ 0–0,4% CPU (шум замера) и ≈ 1,3–2,8 МБ; раскрытая страница настроек 0% CPU в простое, working set 25–40 МБ (40 МБ — после ввода в поле: система подгружает компоненты ввода текста, после сворачивания рабочий набор обрезается как раньше); exe 0,96 МБ.

**Не проверено:** смена цвета Wallpaper Engine «вживую» при смене обоев (проверено чтение текущих значений и перерисовка по сообщению/раскрытию, но смену самого акцента я не запускал); подключение/отключение Wi-Fi и слабый сигнал (виден только случай «подключено»); другие DPI (100/150/200%), второй монитор; страница настроек при радиусе 0 и 30 на всех вкладках (смотрел 14, 20, 26).

Чек-лист этапа 6 (проверить вручную):
1. Шестерёнка справа в ряду вкладок открывает настройки; повторный клик или клик по вкладке возвращает назад
2. Ползунок радиуса: остров светится, пока тянете; углы на всех вкладках выглядят аккуратно и при 0, и при 30
3. Палитра: квадрат и полоса оттенка меняют цвет живьём; `#RRGGBB` применяется; готовые темы переключают сразу; после перезапуска цвета на месте
4. «Цвет системы»: остров принимает цвета Windows; смените обои (Wallpaper Engine/автоакцент Windows) — цвет следует за ними
5. Выключите вкладку — она исчезает из ряда; стрелками переставьте порядок; после перезапуска всё сохранилось
6. Свёрнутый остров без музыки: раскладка слева меняется при Alt+Shift/Win+Space (до 0,4 с), время идёт, значок Wi-Fi меняется при отключении сети; с музыкой — мини-плеер как раньше
7. «Сбросить внешний вид» возвращает золото на чёрном, радиус 14, все вкладки в исходном порядке

## Этап 7. Улучшения после выпуска — СДЕЛАНО (ждёт проверки на живом экране)

Код: `src/bg.rs` (профили Wi-Fi, Bluetooth-аудио через `IKsControl`, строка статуса списков), `src/tabs/controls.rs` (действия по клику, форма пароля), `src/ui.rs` (поле пароля), `src/live.rs` + `src/main.rs` (анимация эквалайзера), `Cargo.toml` (`Win32_Media_KernelStreaming`, `windows-collections`). Собрано без предупреждений, `cargo test` — 82 теста (добавились параметры и XML профиля Wi-Fi).

- [x] **Wi-Fi прямо из острова** (стрелка у плитки Wi-Fi → список): сохранённая сеть — клик подключает; подключённая — клик отключает; открытая — подключается сразу; новая защищённая (значок замка) — на месте списка поле пароля (точки вместо символов, копировать нельзя), Enter или «Подключить». Остров создаёт профиль WLAN (WPA/WPA2/WPA3-Personal, AES/TKIP) и ждёт результата до 20 с; при неудаче («неверный пароль?») профиль удаляется, чтобы Windows не повторяла попытки. Корпоративные сети (логин/сертификат) и WEP по-прежнему открывают Параметры. Подключение идёт в отдельном потоке — громкость и плеер не подвисают
- [x] **Bluetooth-наушники и колонки подключаются из острова**: у аудиоустройств в списке Bluetooth подпись «нажмите, чтобы подключить», клик подключает, по подключённому — отключает. Механизм — свойство драйвера `KSPROPSETID_BtAudio` (ONESHOT_RECONNECT/DISCONNECT) через `IKsControl`, как у кнопки «Подключить» в Windows и утилиты ToothTray; устройство сопоставляется с конечной точкой звука по ContainerId. Если Bluetooth выключен, остров сам включает его и ждёт загрузки драйвера (до 10 с). После подключения наушники становятся основным устройством вывода. Мыши, клавиатуры, геймпады и телефоны — публичного API нет, клик открывает Параметры
- [x] **Звук**: в списке «Аудио» кроме активных устройств показаны отключённые Bluetooth-наушники («Bluetooth • не подключено»): клик подключает их и делает основными; клик по активному устройству, как и раньше, делает его основным
- [x] Строка статуса в заголовке списка: «Подключение…», «Подключено», «Не подключилось — неверный пароль?» и т. п. (гаснет через 6 с); пока действие идёт, повторные клики игнорируются
- [x] **Анимация эквалайзера** в мини-плеере: три столбика плавно качаются (на каждый — сумма двух синусов со своими частотами, не под музыку). Кадры — от таймера мини-плеера 33 мс (≈30 кадр/с), только пока мини-плеер виден и трек играет; на паузе и в «чёлке» таймера нет

Проверено мной: списки на этом ПК (Wi-Fi с замками, JBL Tune 770NC и realme Buds Air 5 распознаны как подключаемые, в «Аудио» они же как «не подключено»), форма пароля (маска, подсказка «не меньше 8 символов», «Отмена»), CPU свёрнутого острова 0,5% одного ядра. **Не проверено:** реальное подключение (к чужой сети не подключался; Bluetooth на ПК был выключен, включать не стал), анимация эквалайзера глазами (музыка стояла на паузе).

Чек-лист этапа 7:
1. Wi-Fi: клик по новой защищённой сети → пароль → «Подключено»; неверный пароль → «Не подключилось — неверный пароль?», сеть не остаётся в сохранённых; клик по подключённой сети отключает
2. Bluetooth (адаптер выключен): клик по наушникам включает Bluetooth и подключает их, звук переключается на них; повторный клик отключает
3. «Аудио»: отключённые наушники в списке, клик подключает
4. Включить музыку при свёрнутом острове: столбики справа в мини-плеере плавно двигаются; пауза — плашка уходит, CPU снова ≈ 0%

## Риски и открытые вопросы

| Риск | Что делать |
|---|---|
| Night Light без публичного API | Делать в последнюю очередь, на реестре; допустимо убрать |
| GPU-загрузка через PDH нестабильна | Для NVIDIA — NVML как запасной путь |
| Календарь | **Решено:** Google Calendar через «секретный адрес в формате iCal» (обычный `.ics` по ссылке, без OAuth), обновление раз в 10–15 мин, только чтение |
| Ввод текста в окне без фокуса | **Решено:** по клику в поле остров временно становится активным окном и принимает клавиатуру; при уходе из поля/сворачивании фокус возвращается предыдущему окну. Глобальный хук не используем |
| Регион окна отстаёт от картинки на быстрой анимации | Подтверждено пользователем (этап 0). Если появится срез краёв — увеличить запас у `hit_rect()` |
| Опрос развёрнутого окна раз в 400 мс | Единственный таймер в простое; если мешает «0% CPU» — заменить на `EVENT_OBJECT_LOCATIONCHANGE`, ограниченный потоком активного окна |
| RAM | Закрыто на этапе 1: trim после каждого сворачивания. Следить, чтобы вкладки этапа 3 не раздували раскрытое состояние выше 30 МБ |
| Fullscreen-игры | Прятать остров, не отнимать фокус (в списке Apps есть Minecraft, Valorant). Borderless-игры пока дают полоску, а не скрытие |
| Глобальная горячая клавиша | `Ctrl+Alt+Space` может быть занята другой программой — тогда в логе ошибка регистрации; сменить `hotkey` в `config.toml` и «Перечитать конфиг» |
| Смена устройства звука | Использует недокументированный `IPolicyConfig`: на будущих сборках Windows может перестать работать (ошибка в логе, список останется) |
| Подключение Bluetooth-аудио | Свойство драйвера `KSPROPSETID_BtAudio` не документировано для приложений; если Windows его уберёт — «Не удалось подключить» и ошибка в логе, тогда только через Параметры |
| Горячие зоны на других мониторах | Окно 2 px по верхнему краю перехватывает клики в этой полоске (180 px по центру) — как и сам свёрнутый остров на своём мониторе |
